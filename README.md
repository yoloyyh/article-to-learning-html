# Article to Learning HTML

把一篇文章变成适合初学者阅读的中文学习网页。提供文章链接、正文或文件，skill 会梳理核心问题和观点，用清晰的解释与合适的图示帮助读者理解，并生成一个可在浏览器中打开的 HTML 文件。

## 能做什么

- **梳理文章重点**：提炼文章要回答的问题、主要观点、适用条件与局限。
- **降低理解门槛**：解释关键术语，按需补充教学示例、对比、练习或交互演示。
- **按内容选择呈现方式**：流程适合用步骤图，对比适合用表格，简单文章也可以保持简洁的静态排版。
- **交代信息来源**：区分原文观点与教学解释，标注来源和实际阅读范围。
- **生成便于阅读的页面**：默认输出单个自包含的中文 HTML，兼顾桌面、手机和基本无障碍阅读。

## 适用场景

- 想读懂一篇技术文章、研究介绍或产品发布文章。
- 想把复杂概念整理成适合初学者的可视化学习材料。
- 想将文章摘要、术语解释与案例放在同一个页面中。

如果只需要普通翻译、简短摘要或浏览网站，可以直接提出需求，不必使用此 skill。

## 安装

将仓库克隆到 Codex 的技能目录：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/yoloyyh/article-to-learning-html.git ~/.codex/skills/article-to-learning-html
```

如果目标目录已经存在，请先检查已有内容；`git clone` 不会覆盖非空目录。安装后，在新的 Codex 对话中使用。

## 使用示例

在 Codex 中提供文章和期望的输出方式，例如：

> 请用 article-to-learning-html 把这篇文章做成中文学习网页：
> https://example.com/article

也可以直接提供文章正文或文件，并说明读者背景、想重点了解的部分或视觉偏好。默认面向零基础的成年读者，使用简体中文。

## 内容与来源

skill 会根据实际可读取的内容制作页面。遇到登录、付费墙或缺失的图片与表格时，它会说明覆盖范围，而不会将未读内容当成事实补全。

翻译和摘要的范围取决于用户提供的内容、已确认的许可以及运行环境适用的规则。页面会标明内容是翻译还是摘要，并将原创教学示例与原文观点区分开。

## 文件结构

```text
article-to-learning-html/
├── SKILL.md                         # 触发条件与执行流程
└── references/
    ├── editorial-contract.md        # 内容、来源和讲解规范
    └── html-contract.md             # 页面视觉、交互和检查规范
```

生成的学习页面默认作为本地 HTML 文件交付，不会自动发布到互联网。
